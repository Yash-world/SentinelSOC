Security & Credential Management

Credential Isolation
Separate token per source
Transport Security
HTTPS recommended
Token Storage
Store token hashes server-side
Revocation
Revoke compromised credentials
  • Never commit bearer tokens to source control.
  • Never expose tokens in query strings or application logs.
  • Protect connector management routes with authentication and CSRF validation.
  • Do not display a token again after its one-time creation view.
  • Restrict ingestion endpoints to authorized sources where practical.
